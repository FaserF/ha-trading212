# Security Policy

## Supported Versions

Only the latest stable release receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1.x | :white_check_mark: |
| < 0.1.x | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project:

1. **Do not create a public GitHub issue.**
2. Send a report via email to `github@fabiseitz.de` or use GitHub Private Vulnerability Reporting if enabled.
3. Provide details about:
   - Component / area affected
   - Reproduction steps or proof of concept
   - Potential impact
4. You will receive an initial response within 48 hours.
5. Once a fix is verified, a patch release and security advisory will be issued.
